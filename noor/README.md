# نور ملهم — دليل التشغيل

## 1) الإعداد (مرة واحدة)
1. أنشئ مشروعاً في https://console.firebase.google.com وفعّل: Authentication (Email + Facebook)، Firestore، Storage، Functions (يتطلب خطة Blaze).
2. للدخول بفيسبوك: أنشئ تطبيقاً في Facebook Developers وضع App ID و Secret في Authentication > Facebook، وأضف رابط الـ redirect الذي يظهر لك.
3. انسخ إعدادات الويب إلى `public/index.html` (المتغير `cfg`).
4. ثبّت الأدوات ثم انشر:
```
npm i -g firebase-tools && firebase login
cd functions && npm i && cd ..
firebase deploy
```
## 2) أن تصبح المالك
بعد أن تسجّل حساباً في الموقع: من Firestore Console أنشئ مجموعة `admins` ومستنداً **رقمه = UID حسابك** (تجده في Authentication > Users) بأي حقل. ستظهر لك تبويبة «لوحة المالك».
## 3) تحميل القرآن
`GOOGLE_APPLICATION_CREDENTIALS=serviceAccount.json node scripts/seed-quran.js`
(للتفاسير والفتاوى والأحاديث: أضفها من لوحة المالك أو بسكربت مشابه، بعد التأكد من مصدرها وترخيصها).
## 4) ما هو موجود / غير موجود
موجود: حسابات، فيسبوك، منشورات بصور وفيديو، لايكات، إشعارات، ملفات شخصية، متصل/غير متصل، رسائل خاصة، مكالمات فيديو (WebRTC)، محتوى متجدد، مسابقات محمية من الغش، مساعدة بخصم نقاط، شارات، توثيق تلقائي عند 10000 نقطة، متصدرون، هدايا نقاط، إعلانات بأماكن عشوائية، لوحة مالك.
غير موجود بعد: الجروبات، تحدي الأصدقاء المباشر، المتجر، إشعارات الموبايل (FCM)، العمل بدون إنترنت (PWA)، أسئلة المقال، مواقيت الصلاة، ألعاب الأطفال، تغيير اللوجو والخط من اللوحة.
ملاحظة: مكالمات WebRTC قد تحتاج خادم TURN خلف بعض الشبكات.
